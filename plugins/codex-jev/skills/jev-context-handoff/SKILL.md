# Jev context handoff

このスキルは、次の話題に関係する原文だけを残した引き継ぎパケットを作る。

## 手順

1. ユーザーが指定した「次の話題・次のステップ」を `nextTopic` にする。推測が必要なら、ツールを呼ぶ前に短く確認する。
2. 現在見えている会話から、順序を保った `blocks` を作る。隠れた履歴や存在しない発言を補わない。
3. 各ブロックに一意の `id`、`role`、原文の `content` を入れる。未解決事項には `status: open`、必ず残すものには `pin: true` を付ける。
4. `jev_context.curate_context` を一度呼ぶ。
5. `retained` を順序どおり使って引き継ぎを提示し、`removed` はIDと除外理由だけを示す。

## 守ること

- これは現在の会話履歴を削除・書き換える機能ではない。新しいタスク／会話へ渡すコンテキストを作る機能である。
- 一般的な `/compact` の代替として会話全体を要約しない。判断基準は常に `nextTopic` との関連性にする。
- `retained.content` は勝手に言い換えない。追加の短い見出しは付けてもよい。
- `status: unchanged` の場合は、何も削られなかった理由と警告をそのまま伝える。
- 元の会話を正本として扱う。Jevの選別は損失を伴い得るため、元データを削除しない。
- APIキー、トークン、パスワードらしい文字列をプロンプトや設定ファイルへ書かない。
